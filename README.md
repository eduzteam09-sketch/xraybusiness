# AI Business Health Checkup

Bản đồ sức khỏe doanh nghiệp & chẩn đoán chiến lược 90 ngày dành cho CEO.

## Giới thiệu
Ứng dụng hỗ trợ lãnh đạo và CEO thực hiện check-up toàn diện sức khỏe doanh nghiệp:
- **Bản đồ sức khỏe đa chiều**: Tài chính, Vận hành, Nhân sự, Thị trường, Công nghệ & AI.
- **Phát hiện điểm nghẽn (Bottlenecks)**: Định vị chính xác rủi ro và các nút thắt tăng trưởng.
- **Kế hoạch hành động 90 ngày**: Lộ trình cải thiện nhanh chóng với các mốc thời gian rõ ràng.
- **Báo cáo CEO Executive**: Tự động tổng hợp và trích xuất báo cáo chiến lược.

## Cài đặt và Khởi chạy

```bash
# Cài đặt thư viện phụ thuộc
npm install

# Khởi chạy máy chủ phát triển
npm run dev
```

## Công nghệ sử dụng
- **Frontend**: React 18, TypeScript, Tailwind CSS, Lucide Icons, Motion
- **Backend**: Express, Node.js
- **AI Engine**: Google Gemini API (@google/genai)
